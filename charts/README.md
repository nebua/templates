# NebuaCloud Catalog Charts

Public Helm charts for marketplace and managed service deployments used by customer-side Argo CD instances.

Custom application runtime charts stay in `app-charts/charts`:

- `app-charts/charts/web-app`
- `app-charts/charts/api-app`

NebuaCloud private CI/CD infrastructure remains in the private `k8s/cicd-infra` source and is not mirrored here.
